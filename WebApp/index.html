⌨️ Keyboard Shortcuts

Aurora Editor runs entirely in this browser tab — nothing to install.

  • Type < for tag completions, or a snippet trigger like html5 then Tab.
  • Typing > after an opening tag inserts the closing tag automatically.
  • Chromium browsers (Chrome/Edge) can open a real folder and save changes back to disk. Other browsers fall back to file pickers and downloads.
